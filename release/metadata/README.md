# App Store 등록 초안

`ko/`, `en-US/`는 App Store Connect에 복사할 상품 페이지 문구입니다. 자동 업로드 설정은 아닙니다. 영어 상품 페이지를 준비한 것이며, 앱의 실제 지원 언어는 빌드에서 확인해야 합니다.

`app.json`의 미확인 필드는 실제 값으로 완성해야 합니다. 권리자의 저작권 표기, 심사 연락처와 설문으로 계산된 콘텐츠 등급이 남았습니다. 공개 지원 이메일은 사용자 허용으로 `sp040122@gmail.com`을 반영했습니다. 심사 연락처는 이름·전화번호까지 실제 값을 필요로 합니다.

공개 페이지:

- 지원: https://ddakphoto-support.sp040122.chatgpt.site/support.html
- 개인정보처리방침: https://ddakphoto-support.sp040122.chatgpt.site/privacy.html

두 URL은 `app.json`에 반영했습니다. `copyright`는 App Store 계정의 실제 권리자 정보를 확인하기 전까지 비워둡니다.

- 앱 이름·부제: 각각 30자 이내
- 홍보 문구: 170자 이내
- 설명: 4,000자 이내
- 키워드: UTF-8 100바이트 이내
- 심사 메모: 4,000바이트 이내
- 첫 출시에는 “이 버전의 새로운 기능”을 작성하지 않습니다.
- 한국 기준 2,200원은 아직 사용자 승인을 받지 않은 제안값입니다. App Store Connect에서 사용 가능한 가격을 확인하고, 다른 국가의 자동 환산 가격을 확인합니다.
- 콘텐츠 등급은 설문 답변으로 Apple이 계산한 실제 값을 기록합니다.
- 스크린샷은 Mac의 실제 앱 실행 화면으로 준비합니다. 미리보기 디자인을 실행 화면으로 제출하지 않습니다.

초안 설명의 기능과 개인정보 문구를 최종 배포 빌드와 대조한 뒤 제출하세요. 상세 절차는 [출시 체크리스트](../../docs/release-checklist.md)를 참고하세요.

## 제출 전 로컬 검사

```sh
python3 -m unittest discover -s scripts -p 'test_*.py'
python3 scripts/verify-metadata.py
python3 scripts/verify-metadata.py --submission
```

기본 모드는 초안의 필수 문구·글자/바이트 한도·URL 형식·아이콘과 로컬 스크린샷의 헤더를 검사합니다. `--submission`은 미완성 심사 정보와 가격 확인 등도 오류로 처리합니다. 현재는 미완성 항목이 있어 이 모드가 실패하는 것이 정상입니다. `--json`으로 기계 판독용 결과를 받을 수 있습니다.

이 검사는 로그인하지 않고 네트워크 요청도 하지 않습니다. 성공하더라도 Apple 계정·서명·실기기 검증·실제 업로드·심사 승인 상태를 보장하지 않습니다. 스크린샷 헤더 검사는 화면 내용이나 전체 이미지 디코딩 검증을 대신하지 않습니다. 검증 산출물에서 복원한 실제 화면은 별도로 눈으로 확인합니다. 연락처·정산 정보·키는 공개 저장소에 추가하지 않습니다.
