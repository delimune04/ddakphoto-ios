현재 딱사진 앱에는 사진이나 개인 정보를 개발자 서버로 전송하는 기능이 없습니다. 회원가입, 광고, 분석·추적 SDK, 앱의 서버 통신도 없습니다.

2. 선택한 사진의 처리

앱은 시스템 사진 선택기에서 사용자가 선택한 사진을 가져와 기기 안에서 JPG로 변환합니다. 전체 사진 보관함의 읽기 권한을 요구하지 않습니다. iCloud에만 저장된 원본을 고르면 Apple 사진 서비스가 원본을 내려받아야 할 수 있습니다.

원본 사진은 수정하거나 삭제하지 않습니다. 결과 파일을 새로 생성하며, 원본의 EXIF 정보와 촬영 위치 정보를 결과 파일에 복사하지 않습니다.

3. 임시 파일과 보관

선택한 사진의 작업용 사본과 변환 결과는 앱의 임시 저장 공간에 보관됩니다. 사용자가 화면에서 선택 사진과 결과를 지우거나 앱을 다음에 실행할 때 작업용 파일을 정리합니다. 앱을 삭제하면 앱의 로컬 데이터도 제거됩니다.

사진 보관함에 저장하거나 다른 앱으로 공유한 사본은 앱의 임시 결과와 별개입니다. 이런 사본은 해당 보관함이나 서비스를 통해 관리해야 합니다.

4. 권한과 사용자의 선택

사진 보관함에 결과를 저장할 때 사진 추가 전용 권한을 요청합니다. 이 권한은 새 사진 추가에 사용합니다. 저장 권한을 허용하지 않아도 사진 변환과 시스템 공유는 사용할 수 있습니다.

사용자가 시스템 공유 메뉴에서 파일을 전달하면 선택한 앱이나 서비스가 사본을 처리합니다. 그 이후의 보관·전송에는 해당 대상의 정책이 적용됩니다.
